# 供电维（日照/日影）与热维（凉星/热星）术语正交化

早期口语与过渡文档中，「阴影」一词同时被用来指代「进入地球背阳区靠电池限功运行」与「温度低、散热余量大、适合承接迁移」两种截然相反的物理状态：前者是算力受限的**迁出源**，后者是算力充沛的**迁入目标**。

为消除代码、配置与论文表述中的歧义，我们将节点物理状态拆分为两个正交维度并固定四个规范术语（同步收录于 `GLOSSARY.md`）：

1. **供电维（由确定性轨道星历决定）**：
   - **日照**（`sunlit`，`not w.is_eclipse(j, t)`）：太阳翼供电，功率上限 `P_max`；
   - **日影**（`eclipse`，`w.is_eclipse(j, t)`）：电池供电封顶 `P_dark`，限频或屏蔽高功耗档，作为迁出源。
2. **热维（由一阶 RC 热模型状态决定）**：
   - **凉星**（`cool`，`w.is_cool(j, margin_C)`）：结温距温限有充足裕度；**日照 + 凉星**（典型如刚出日影的算力星）为首选迁入目标；
   - **热星**（`hot`，`w.is_hot(j)` 或前瞻窗口内越过温限）：作为迁出源。

代码标识符、注释与实验报告中禁止再出现 `shadow` 或 `dark=cool` 的混用写法。
