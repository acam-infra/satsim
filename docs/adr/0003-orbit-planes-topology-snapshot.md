# 第二拓扑：轨道推导的连边快照

默认仍是 `topology: ring`（紧凑舱段）。现准入可选 `topology: orbit_planes`：用声明式壳层/角色 + 解析圆轨位置，在**仿真启动时**生成一次无向 ISL 邻接；路径仍走图上 BFS，流体 `Net` / 迁移 / 调度臂不改语义。

动机是争用故事需要「遥感轨 + 算力轨」这类跨轨共享边，而不是把 Walker 或全星座引擎搬进仓库。连接方法按轨道几何通用，与是否叫 Walker 无关。

刻意不做：内嵌完整星座仿真（对照 ssim 只借鉴「轨道→连边」分层，不引入子模块）；每 tick 重算可见性；包级路由；放开无边上限的任意自定义图 DSL。`nodes` 在 `orbit_planes` 下仅放宽到 2..16。场景镜像须把「连续星历驱动 / 时变重连」留在 `not_modeled`。
