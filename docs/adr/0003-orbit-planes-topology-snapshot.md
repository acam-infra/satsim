# 第二种拓扑：基于轨道平面几何的静态星间拓扑（`orbit_planes`）

除了默认的四星环拓扑（`topology: ring`）外，新增支持静态轨道拓扑（`topology: orbit_planes`）：在**仿真启动时**，根据配置声明的轨道平面参数（高度、倾角、相位）和最大星间通信距离，计算一次解析圆轨位置并生成无向星间链路邻接图。后续的最短路寻路（BFS）、流体网络带宽分配、请求迁移和三档调度策略逻辑完全复用，不做改动。

引入该拓扑是为了构造“遥感星轨道 + 算力星轨道”跨轨共享瓶颈链路的争用场景，而不需要把整套重型 Walker 星座或逐时刻星历引擎搬进仓库。

刻意不做的事：不内嵌完整星座运动引擎、不在每个仿真步重算星间可见性、不做包级路由、也不开放无限制的任意自定义图语法。`orbit_planes` 模式下节点数上限放宽至 2–16 颗；对应的场景背景说明（`scene_*.yaml`）必须在 `not_modeled` 中明确注明“不包含连续星历运动与时变断链重连”。
